# The Geometry of Emotion: Physics-Based Springs in Modern Web Interfaces

For decades, digital motion on the web has been constrained by static duration-based curves: `ease-in-out`, `cubic-bezier(0.4, 0, 0.2, 1)`, and fixed millisecond timers. 

Yet in the physical universe, an object set into motion possesses **mass**, experiences **tension**, and dissipates energy through **friction**. It never moves according to an arbitrary timer—if interrupted mid-flight, its momentum carries forward continuously.

In this essay, we examine why duration-based transitions feel mechanical, explore analytical spring mechanics, and build a production-ready mass-spring model in TypeScript.

---

## 1. The Interruption Problem in CSS Animations

Consider a user dragging a modal drawer. When the user releases their finger, the drawer has an instantaneous velocity *v0*.

In traditional CSS transition paradigms:
```css
/* The traditional flaw: resetting velocity to zero */
.drawer {
  transition: transform 300ms ease-out;
}
```

When an element transitions with CSS, the browser cancels any existing velocity, starting the animation from rest (*v = 0*). This creates a visible discontinuity—a visual jolt that breaks the illusion of physical reality.

True physics-driven interfaces do not define *duration*; they define **material properties**:
- **Stiffness (k)**: The restorative tension pulling the object toward equilibrium.
- **Damping (c)**: The resistance force opposing velocity, preventing perpetual oscillation.
- **Mass (m)**: The inertia resisting acceleration.

---

## 2. Regimes of Harmonic Motion

A damped harmonic oscillator behaves across three distinct regimes:

1. **Underdamped (damping ratio under 1.0)**: The spring overshoots the target and oscillates before settling. Ideal for playful buttons and bouncy badges.
2. **Critically Damped (damping ratio equal to 1.0)**: The fastest return to equilibrium without any overshoot. The gold standard for navigation menus, sheets, and high-frequency UI elements.
3. **Overdamped (damping ratio over 1.0)**: Sluggish return without overshoot, mimicking motion through viscous fluid.

## 3. Analytical TypeScript Implementation

Instead of step-by-step numerical approximation which can accumulate drift, we can solve the harmonic equation analytically:

```typescript
export interface SpringConfig {
  stiffness: number; // e.g. 170
  damping: number;   // e.g. 26
  mass: number;      // e.g. 1
}

export class AnalyticalSpring {
  private w0: number;  // natural frequency
  private zeta: number; // damping ratio
  private wd: number;  // damped frequency

  constructor({ stiffness, damping, mass }: SpringConfig) {
    this.w0 = Math.sqrt(stiffness / mass);
    this.zeta = damping / (2 * Math.sqrt(stiffness * mass));
    this.wd = this.zeta < 1 ? this.w0 * Math.sqrt(1 - this.zeta * this.zeta) : 0;
  }

  public evaluate(t: number, x0: number = -1, v0: number = 0): number {
    if (this.zeta < 1) {
      const envelope = Math.exp(-this.zeta * this.w0 * t);
      const c1 = x0;
      const c2 = (v0 + this.zeta * this.w0 * x0) / this.wd;
      return envelope * (c1 * Math.cos(this.wd * t) + c2 * Math.sin(this.wd * t));
    } else if (this.zeta === 1) {
      const envelope = Math.exp(-this.w0 * t);
      return envelope * (x0 + (v0 + this.w0 * x0) * t);
    } else {
      const s1 = -this.w0 * (this.zeta - Math.sqrt(this.zeta * this.zeta - 1));
      const s2 = -this.w0 * (this.zeta + Math.sqrt(this.zeta * this.zeta - 1));
      const c2 = (v0 - s1 * x0) / (s2 - s1);
      const c1 = x0 - c2;
      return c1 * Math.exp(s1 * t) + c2 * Math.exp(s2 * t);
    }
  }
}
```

## 4. Performance & 60 FPS Guarantee

Evaluating physics on the main thread requires strict architectural discipline:

1. **Only animate transform and opacity**: These properties skip both layout calculation and paint phases, executing directly on the GPU compositor thread.
2. **Precompute curves for simple states**: For non-interactive transitions with known start/end points, generate CSS easing curves ahead of time.
3. **Always honor prefers-reduced-motion**: Users sensitive to vestibular motion should receive immediate snap transitions without spring reverberations.

```css
@media (prefers-reduced-motion: reduce) {
  * {
    animation-duration: 0.001ms !important;
    transition-duration: 0.001ms !important;
  }
}
```
